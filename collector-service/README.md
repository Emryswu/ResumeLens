# 独立浏览器采集服务

需要 Node >=22.13.0 和 Chrome。后端通过本地 HTTP 调用，不需要 MCP。

在本目录运行 `npm ci`，复制 `.env.example` 为 `.env`，将 `COLLECTOR_TOKEN` 换成随机密钥。启动后端时设置同一个 `COLLECTOR_TOKEN`，然后在本目录执行 `npm start`。默认监听 `127.0.0.1:3108`；后端可用 `APP_COLLECTOR_URL` 更改地址。

在助手输入框左下角的 + 菜单里选择「独立浏览器」。第一次采集会弹出专用 Chrome 窗口，在这个窗口登录 BOSS 后再次采集即可。配置目录在 `data/profiles/<用户 id>`，重新启动服务不会丢失登录状态；`COLLECTOR_DATA_DIR` 可改存储位置。每个会话的搜索和详情共用一个标签页，结束后保持打开。

「自动」优先使用插件。插件缺失、版本不支持或明确在加载页面前失败时，代码切换到独立浏览器，并记录切换原因。「我的 Chrome」和「独立浏览器」固定使用选定方式。验证码、未登录、已经加载过页面或无法确认是否加载过页面时不切换，保留原结果，避免重复读取。

两种方式共用后端每日 30 页额度及 JobSearchWorkflow 的每轮采集/页数/核实次数上限。后端先预留本次页数，只有明确的实际加载页数报告才能退回未用额度；取消、超时或失联保留预留额度。服务复用插件的采集 runner，每次打开和翻页均扣额度、连续访问间隔 3–7 秒。

`npm test` 测 HTTP、鉴权、单标签页和每日额度。`npx patchright install chromium` 后运行 `npm run test:browser`，用本地页面场景验证真实浏览器抓取、横幅、标签页和持久化 cookie；不访问真实招聘数据。CI 会运行这两组测试。
